# CSI Hackathon Landing Page

## Project Overview
An interactive hackathon-themed landing page created as a web development project. The page presents event information through a visually engaging and responsive interface.

## Features
- Responsive landing page layout
- Hackathon event information and highlights
- Interactive and visually engaging sections
- Custom image assets
- Responsive styling for different screen sizes

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript

## Setup Instructions
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser or use the Live Server extension.
